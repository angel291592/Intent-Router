# Intent-Router

> Converge a vague request into a structured, machine-consumable intent contract — deciding when to probe, when to ask, and when to halt, before any routing happens.

**Status: under active development.** Full documentation, the skill spec, and usage guides are coming soon.

## Why

Every router/clarify tool today answers a three-way question: route, clarify, or fall back. None of them ask the cheaper question first: *can the missing information be found without bothering the user?* Intent-Router adds that fourth state — **PROBE** — and treats "ask a human" as the last resort, not the default.
